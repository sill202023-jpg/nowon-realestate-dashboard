`index.html`은 GitHub Pages에 게시되는 전체 화면입니다. API 요청은 별도의 서버로 전달하며 인증키는 서버의 비밀 환경변수에서만 사용합니다.

API 서버: https://nowon-xi-briefing-20261110.pipedbug3.chatgpt.site

GitHub 저장소에는 API 키를 저장하지 않습니다. GitHub Pages는 정적 호스팅이므로 API 서버가 별도로 필요합니다.

## GitHub Pages 설정

저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 선택합니다. `main`에 푸시하면 포함된 워크플로가 `index.html`을 배포합니다.

## 데이터 해석

Top 10은 선택 기간의 단지별 최근 계약금액 순이며 월세는 월 임대료 순입니다. 면적이 혼합되며 투자수익률 순위가 아닙니다. 동별 목록에는 선택 기간에 거래된 단지가 표시됩니다.

샘플 추천매물은 실제 중개의뢰 매물이 아닙니다. 직접 추가한 매물은 해당 브라우저에 저장됩니다. 주변 시설은 지도 제공기관의 수록 범위에 따라 누락될 수 있습니다. 학교 배정·KTX 운행·개발계획 최신 단계는 공식 기관 자료로 확인해야 합니다.
